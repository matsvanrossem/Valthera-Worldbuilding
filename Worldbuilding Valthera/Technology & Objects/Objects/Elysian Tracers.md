# Elysian Tracers

Wondrous item, rare
These delicate silver bracelets are imbued with the
elemental magic of the plane of air. While wearing them, the
user gains the following benefits:
Flight: The user gains a flying speed of 60 feet. Feather
Fall: The user can cast Feather Fall once per long rest. Misty
Step: The user can cast Misty Step once per long rest. In
addition, when the user is in an area of strong wind (such as
a storm or the gusts of a powerful creature), the Elysian
Tracers resonate with the elemental energy and grant the
user advantage on Strength or Dexterity checks to resist
being moved or knocked prone by the wind.
